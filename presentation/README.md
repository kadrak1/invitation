# Gardenscapes vs Royal Match — презентация (тестовое задание Junior Game Designer, Playrix)

## Файлы

- `gardenscapes_vs_royal_match.pptx` — готовая презентация (8 слайдов, 16:9)
- `build_presentation.py` — скрипт-генератор презентации
- `render/` — превью слайдов (PNG + PDF)

## Как открыть в Google Slides

1. Откройте [slides.google.com](https://slides.google.com) и создайте новую пустую презентацию.
2. Меню **Файл → Импортировать слайды** (File → Import slides).
3. Вкладка **Загрузка**, выберите `gardenscapes_vs_royal_match.pptx`.
4. Отметьте «Все» слайды и импортируйте.

Либо просто загрузите `.pptx` на Google Диск и откройте его через Google Slides — файл сконвертируется автоматически.

## Перед отправкой

- Замените плейсхолдеры `[Ваше имя]` и `[email / telegram]` на титульном и финальном слайдах.
- При желании добавьте скриншоты обеих игр (например, на слайды сравнения механик).
